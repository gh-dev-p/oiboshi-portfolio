# 用語集

**追星（oiboshi）**

- 対象プロジェクト：追星（oiboshi）
- 本書の位置付け：ドキュメント・アプリの文言・Issue で使う用語の表記をそろえる。同じ概念には、1つの表記だけを使う

---

## 1. 人と役割

| 用語 | 定義 | 使わない表記 |
| --- | --- | --- |
| ユーザー | アプリを使う人。起動時に、匿名でサインインする。全員が、ファンとして推しを追える | アカウント（人を指すとき） |
| ファン | ある発信者から見て、その発信者のチームメンバーでないユーザー。推しを追う側として使う | ユーザー（ファンとチームメンバーを分けるとき） |
| 発信者 | 配信・投稿・予定を、追星に出す顔。ユーザーとは別のもので、チームが運用する | クリエイター、配信者、ストリーマー |
| 推し | ファンがフォロー中の発信者 | お気に入り |
| チーム | 1人の発信者を運用するユーザーの集まり。発信者ごとに1つ | クリエイターチーム、事務所（追星の言葉として） |
| チームメンバー | チームに入っているユーザー。ログイン方法が要る。役割は、オーナーと一般メンバー | 運用メンバー、クリエイターユーザー |
| オーナー | チームメンバーの役割。チームに1人。発信者の課金を持つ | 持ち主 |
| 一般メンバー | チームメンバーの役割。オーナーでないチームメンバー | 管理者 |
| 確認用の発信者 | 動作の確認のために、運営が SQL で入れた発信者。プランが確認用。公開の前に消す | テスト用の発信者、ダミー、デバッグユーザー |
| 運営 | 追星を運営する側。アプリの中に役割を持たず、SQL で、確認用の発信者・プラン・優先のフラグ・受付・停止を入れる | 管理者 |

## 2. 内容

| 用語 | 定義 | 使わない表記 |
| --- | --- | --- |
| 配信 | ライブ配信。ツイキャス・Twitch・YouTube のもの | ライブ（単独で） |
| 配信中 | いま配信している状態。サーバーが1分ごとに確かめる | オンエア |
| 投稿 | 長尺動画・ショート動画・画像・テキストの投稿。YouTube・Instagram・X のもの | ツイート |
| 新着 | 推しのページを最後に見たあとの投稿 | 未読 |
| 予定 | 予約とイベントの公演をまとめた呼び名 | － |
| 予約 | 配信の、開始予定の時刻。配信サービスから取る | 配信予定 |
| イベント | 発信者が手で登録する予定。会場で行うライブなどの公演で、プラットフォームを持たない。発信者が手で作る予定は、イベントの公演だけ（2026-11-09。前の「カレンダー予定」はなくした）。画面で「チケット」と呼ぶのは、イベントの公演のリンク | カレンダー予定、手動予定 |
| 実績 | 実際に行われた配信と投稿。月のカレンダーとタイムスケジュールに反映する | 履歴 |
| 取得 | サーバー（Edge Functions）が、SNS から更新を取ってデータベースに保存すること | 同期、クロール |
| 定時実行 | pg_cron が、一定の間隔で Edge Functions を呼ぶ仕組み | バッチ |

## 3. 画面と表示

| 用語 | 定義 | 使わない表記 |
| --- | --- | --- |
| 全体タイムライン | ホームの、推し全員の投稿を新しい順に並べた一覧 | フィード |
| 推しレーン | ホームの、推しの丸いアイコンを横に並べた行。配信中・新着ありの印を出す | 推しの行 |
| 埋め込みビューア | ホームの推しレーンの下に置いて、配信を流すもの。ページと一緒にスクロールする。ホームのものだけを指す | 配信ビューア、配信の面 |
| 固定ビューア | 配信か推しの動画を、画面のいちばん上に据え付けて流し続けるもの。下部ナビのスイッチで出し消しする | 小窓、固定モード |
| ランダム再生 | 固定ビューアで、フォロー中の推しの動画を、推しが続かない順に次々に流すこと。画面では「動画シャッフルモード」と呼ぶ | シャッフル再生 |
| 配信モード | 固定ビューアで、配信中の推しの配信を流している状態。動画シャッフルモードと対にして、画面に出す呼び名 | － |
| 推しリスト | フォロー中の発信者の一覧の画面 | フォロー一覧 |
| 推しを探す | 発信者を検索してフォローする画面 | 検索画面 |
| おすすめ | 推しを探すと推しを選ぶで、言葉が空のときに出す発信者 | － |
| 発信者ページ | 発信者のプロフィールと投稿を出す画面。配信中でも同じ見た目で、アイコンに「LIVE」の印と、「固定ビューアで見る」のボタンを出す | プロフィール画面、配信中の発信者ページ（2026-11-19 にやめた画面）、配信スクリーンモード |
| 投稿ビューア | 投稿を全画面で1件ずつ見る画面。上下のスワイプで前後の投稿へ送る | － |
| タイムスケジュール | 縦軸が時間、列が推しごとの表で、推し全員の予定を出す画面 | タイムテーブル |
| 月のカレンダー | 月ごとに、予定と実績を日ごとに出す画面 | － |
| 配信ブロック | 配信とイベントの公演を、時間の長さを持たせて出す四角 | － |
| 投稿チップ | 投稿を、投稿した時刻の位置に出す小さな四角 | － |
| 「+N」 | 近接した投稿をまとめた四角 | － |
| リング | 推しのアイコンの周りの枠。配信中・新着あり・既読を表す（ホームの推しレーンでは、埋め込みビューアで流している推しだけを赤くし、新着は「NEW」の印で表す） | － |
| 状態表示 | 空・読み込めない状態で、画面の中央に出すイラスト・見出し・説明・ボタン | － |
| スケルトン | 読み込み中に出す、画面の形に合わせた灰色の骨組み | － |
| スナックバー | 画面の下に一時的に出す通知 | トースト |

## 4. アカウントと発信者向け

| 用語 | 定義 | 使わない表記 |
| --- | --- | --- |
| 匿名サインイン | 起動時に、入力なしで行うサインイン | ゲストログイン |
| ログイン方法 | ユーザーに結び付けた、Apple・Google・X・Twitch のアカウント。結び付けたどれでもログインできる | － |
| 再認証 | 大事な操作の前に、ログイン方法でもう一度ログインして、本人かを確かめること | － |
| 退会 | ユーザーのデータを消すこと | アカウント削除（ストアの要件を指すときを除く） |
| アカウント連携 | 発信者が、SNS のアカウントを OAuth で確かめ、自分のものとして登録すること | SNS 連携 |
| 確認済み | アカウント連携で、本人のアカウントだと確かめた状態。取得と表示の対象になる | 認証済み |
| 連携の解除 | 確認済みのアカウントを外すこと。内容はすぐに見せなくなり、90日後に消える | － |
| 登録待ちの連携 | 発信者として登録の手順で確かめた、まだ発信者に付いていないアカウント | － |
| 表示するコンテンツ | 連携したアカウントごとに、追星に出す内容（配信・動画・ショート・投稿・予約）の選択 | 表示する内容（この選択を指すとき。スケジュールの絞り込みの見出し「表示する内容」は別のもの） |
| タイプ | 発信者が一覧から3つまで選ぶ、配信の傾向（ゲーム・雑談など）。おすすめに使う | ジャンル |
| 優先のフラグ | 運営が付ける、おすすめに出やすくする印 | － |
| プラン | 発信者の種別と料金の種類。基本プラン・永年無料・運営・確認用 | － |
| 基本プラン | 一般の発信者のプラン。料金はかからない | スタンダードプラン、無料プラン |
| X連携プラン | 基本プランの発信者が使う、X の連携の有料のサブスク（月290円）。商品も「X連携プラン」。機能そのものは「X の連携」と呼ぶ | X のオプション、X プラン |
| 取り戻し | オーナーが退会した発信者を、90日のうちに、SNS の連携で確かめて自分のものに戻すこと | 復元（「購入を復元」を除く） |
| 受付 | 発信者の登録と取り戻しを受け付けるかの、アプリ全体の設定 | － |
| 通報 | ファンが、発信者やイベントの公演の問題を、運営に知らせること | 報告、違反報告 |
| 停止 | 運営が、通報などを確かめて、発信者をファンに見せなくした状態 | 凍結、BAN |
| 表示しない | ファンが、発信者を検索やタイムラインに出さなくすること。本人にだけ効く | ブロック、ミュート |
