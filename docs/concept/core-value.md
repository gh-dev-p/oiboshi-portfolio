# コアバリュー

**追星（oiboshi）**

- 対象プロジェクト：追星（oiboshi）
- 本書の位置付け：アプリのコアバリューだけを短く定める。要件の詳細は本仕様書で扱う

---

## 1. コアバリュー

- 推しの発信者の更新（配信・投稿・予定）を、1つのアプリで追える。

## 2. 誰の、どんな困りごとを解くか

- ファンが、複数のSNSに散らばった推しの更新を、1か所で追えるようにする。
- 発信者に課金してもらい、発信者が予定や連携を登録する。

## 3. やらないこと

- 発信者本人の配信以外を、アプリ内で流さない。
- アプリ内でYouTube動画を見られることを、必須にしない。
